Blackstone

A fast Minecraft Bedrock Edition server written in Rust, with the same world generation as Minecraft Java Edition.

View on GitHub Get started

What works today

Honest status: this is a young project. Some parts are verified in the real game client, others only by automated tests.

World generation Done

Infinite Overworld using the same rules as Java 26.3 (mountains, caves, biomes), saved in Bedrock's LevelDB format. Flat fallback world if the generator is missing.

Networking Done

NetherNet (WebRTC) transport used by Bedrock 26.60+, with HTTP signaling. Join from the Friends/LAN tab.

Creative mode Done

Full creative menu, server-validated block breaking and placing with orientation rules, doors, trapdoors, levers, buttons, saving.

Players & entities Done

Players see each other (movement, skin, held item), dropped items, and a /bot command for testing with one account.

Basic survival Done

Block drops (data from Dragonfly), health, fall damage, hunger, eating, death and respawn, melee combat. Part of it is verified by tests only so far.

Crafting & chests Done

Crafting grid and table, chests with block entities, double chests, multiple players.

Furnace In progress

Smelting is being worked on.

Armor, durability, effects Planned

Armor that reduces damage, tool wear, enchantments, potion effects, lava, fire, drowning.

Mobs Planned

Animals and monsters, starting with simple behavior.

Plugin API Planned

Cancellable events for break, place and interact are part of the design.

Nether & End Planned

Only the Overworld exists today.

Xbox auth & permissions Planned

Login signatures are not verified yet: do not expose a server publicly.

Architecture

Small crates with clear boundaries. The server never links the generator: it starts it as a separate program and talks to it over local TCP, keeping the server MIT and on stable Rust. The game tick never waits for the generator.

Quick start

Build the generator once (needs Internet the first time, it takes a few minutes), then run the server.

# get the code
git clone https://github.com/andre4kk/Blackstone
cd Blackstone

# generator (nightly Rust is picked automatically by rustup)
cd generator
cargo build --release
cd ..

# server: creates server.toml if missing, listens on TCP+UDP 19132
cargo run

In the game, join from the Friends/LAN tab. You start in creative; /gamemode s switches to survival. Do not share identity.key.

How to contribute

Pull requests are welcome. Good places to start:

Ideas for first contributions

  • Armor that reduces damage
  • Tool durability
  • Status effects (poison, potions...)
  • Simple mobs and animals
  • Permission system (today anyone can use /bot)
  • Plugin API (cancellable break/place/interact events)
  • Nether / End groundwork
  • Chest loot and block-entity contents
  • Verifying survival behavior in the real client

Process

  1. Fork the repository and create a branch.
  2. Make your change, with tests.
  3. cargo test --workspace
  4. cargo clippy --workspace --all-targets and cargo fmt --all
  5. Open a pull request describing what you changed and how you tested it.

The generator has its own tests: cd generator && cargo test. crates/protocol/src/generated.rs is generated: do not edit by hand.
